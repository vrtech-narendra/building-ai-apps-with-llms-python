# 🚀 Building AI Applications with LLMs Using Python

> Learn how to build modern AI applications using Large Language Models (LLMs) with Python—from fundamentals to production-ready AI systems.

---

## 📖 About This Repository

Welcome!

This repository contains the complete source code, examples, notes, presentation slides, and projects for the **Building AI Applications with LLMs Using Python** course.

Unlike many AI courses that jump directly into frameworks, this course first builds a solid understanding of **how AI applications actually work**, and then gradually introduces the tools, frameworks, and best practices used in real-world AI development.

By the end of this course, you'll be able to design, build, and deploy production-ready AI applications powered by Large Language Models.
