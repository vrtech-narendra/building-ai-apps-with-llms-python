# 🚀 Building AI Applications with LLMs Using Python

> Learn how to build modern AI applications using Large Language Models (LLMs) with Python—from fundamentals to production-ready AI systems.

---

## 📖 About This Repository

Welcome!

This repository contains the complete source code, examples, notes, and projects for the **Building AI Applications with LLMs Using Python** course.

Unlike courses that jump directly into frameworks, this course first builds a solid understanding of **how AI applications actually work**, and then gradually introduces the tools used in real-world AI development.

By the end of this course, you'll be able to build production-ready AI applications using modern LLM frameworks and APIs.
