# 📘 Module 1: Introduction to Building AI Applications with LLMs Using Python

Welcome to **Module 1** of the **Building AI Applications with LLMs Using Python** course.

This module introduces the core concepts required to understand how modern AI applications are built using Large Language Models (LLMs). Before writing any code, you'll build a solid foundation by learning the AI ecosystem, different AI models, AI developer roles, and how existing LLMs are used in real-world applications.

---

## 🎯 Learning Objectives

By the end of this module, you will be able to:

- Understand what AI applications are and how they work.
- Explain the role of Large Language Models (LLMs) in AI applications.
- Differentiate between various types of AI models.
- Understand the roles of AI Model Developers and AI Application Developers.
- Learn how developers use existing Hosted and Local LLMs to build AI applications.
