# 📘 Section 2: Working with Hosted and Local LLMs

Welcome to **Section 2** of the **Building AI Applications with LLMs Using Python** course.

In this section, you'll learn how to work with both **Local LLMs** and **Hosted LLMs**. You'll set up Ollama, run multiple Open-Weight LLMs locally, understand production deployment concepts, and learn how to access Hosted LLMs from AI providers such as **Groq** using REST APIs.

---

## 🎯 Learning Objectives

By the end of this section, you will be able to:

- Set up a Local LLM environment using Ollama.
- Understand Local LLM architecture and deployment.
- Deploy Ollama in production environments.
- Work with multiple Open-Weight LLMs.
- Choose the right LLM for different AI applications.
- Use Ollama Interactive Mode.
- Understand the difference between Local and Hosted LLMs.
- Configure a Hosted LLM provider (Groq).
- Generate and securely manage API Keys.
- Access Hosted LLMs using REST APIs from Python.
